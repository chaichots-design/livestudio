ติดตั้ง LiveStudio

ผู้ช่วยไลฟ์ขายของ TikTok ใช้ได้ทั้งคอม Windows และมือถือ ฟรี ไม่ต้องสมัคร

เวอร์ชันล่าสุด

💻 คอม Windows

⬇ ดาวน์โหลดตัวติดตั้ง
  1. เปิดไฟล์ที่ดาวน์โหลดมา (อยู่ในโฟลเดอร์ Downloads)
  2. ถ้าขึ้นหน้าต่างสีน้ำเงิน "Windows protected your PC" กด More info แล้วกด Run anyway
  3. เลือกที่วางไอคอน (เดสก์ท็อป / โฟลเดอร์บนเดสก์ท็อป / โฟลเดอร์อื่น)
  4. เสร็จแล้วโปรแกรมเปิดขึ้นเอง ครั้งต่อไปเปิดจากไอคอน ไลฟ์สตูดิโอ
อัปเดต: เมื่อมีเวอร์ชันใหม่ หน้าแรกของโปรแกรมจะบอกเอง ดาวน์โหลดไฟล์ใหม่แล้วเปิดทับได้เลย สินค้าและออเดอร์เดิมไม่หาย
ไม่ต้องใช้สิทธิ์ผู้ดูแลเครื่อง ไม่ต้องต่อเน็ตตอนใช้งาน ใช้ Microsoft Edge ที่มากับ Windows

📱 มือถือ

ไม่ต้องลงแอป เปิดโปรแกรมในเบราว์เซอร์แล้วเพิ่มไว้ที่หน้าจอหลัก จะได้ไอคอนเหมือนแอป ใช้ได้แม้ไม่มีเน็ต

▶ เปิดโปรแกรมบนมือถือ
  1. เปิดลิงก์นี้ใน Safari
  2. กดปุ่ม แชร์ (สี่เหลี่ยมมีลูกศรขึ้น) ด้านล่าง
  3. เลือก เพิ่มไปยังหน้าจอโฮม แล้วกด เพิ่ม
  1. เปิดลิงก์นี้ใน Chrome
  2. กด ⋮ มุมขวาบน
  3. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
ชื่อเมนูอาจต่างไปตามรุ่นเครื่อง

📦 ย้ายสินค้าและออเดอร์มาเครื่องใหม่

  1. เครื่องเดิม: หน้าแรก กด ⬇ สำรองทั้งหมด (หรือ 📤 ติดตั้งเครื่องอื่น แล้วกด ส่งไฟล์สำรอง)
  2. ส่งไฟล์ livestudio-สำรอง-....json ไปเครื่องใหม่ เช่น ทาง LINE ถึงตัวเอง หรือแฟลชไดรฟ์
  3. เครื่องใหม่: หน้าแรก กด ⬆ กู้คืนจากไฟล์สำรอง แล้วเลือกไฟล์นั้น
ไฟล์สำรองมีชื่อลูกค้าและออเดอร์ ส่งไปเฉพาะเครื่องของตัวเอง รหัส OBS และคีย์ AI ไม่อยู่ในไฟล์ ใส่ใหม่ที่เครื่องนั้น
